Process

The shape every change followed

1. Reason and blast radius

What breaks if this is wrong, and which databases and logins are touched.

2. Execute with a floor

Additive first, reversible second: create before drop, enable before restrict.

3. Validate and record

A query that proves the new state, captured with a timestamp and kept with the change.

Not done

Changes deliberately rejected

Enable mixed-mode authentication

Needs a registry change and a service restart. Doing it mid-session would have interrupted the work for no demonstration value.

Drop the "unused" indexes

Four indexes show zero reads, but the workload is a test suite. Dropping them now would be a change made to look decisive.
