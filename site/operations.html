Failure path

Proven, not assumed

A temporary job whose only step throws an error was executed, then the hourly watcher ran and wrote the failure to AFS_Audit.dbo.DbaOpsLog:

job AFS - Demo Failure (watcher test),
step Fail on purpose failed (run_status 0)

Operations log

Every run leaves a row

The procedures that the jobs call write one row per database per run, so a backup that silently stopped producing files is visible as a gap, not as a missing claim.
